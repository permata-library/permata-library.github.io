# PERMATA Library

Public catalogue of PERMATA Library, run by the Librarian Council (Badan Pustakawan) of Kolej PERMATA@Pintar Negara.

Built by **Jacob Chan** & **Mitesh Mithrran**, Librarian Council session 2026/2027.

- Catalogue data: the Librarian Council inventory sheet.
- Book covers: [Open Library](https://openlibrary.org), loaded by cover ID.
- Updating the site: replace `index.html` with a new build and commit. GitHub Pages republishes in about a minute.

Future maintainers: add your names under "Maintained by" below. Keep the credits above.
